# Riad's Portfolio 💻

A modern, responsive, and high-performance personal portfolio website showcasing skills, projects, and career growth.

## 🌟 Features

- **Modern Design**: Clean and professional UI with smooth animations
- **Fully Responsive**: Optimized for all devices (mobile, tablet, desktop)
- **Performance Optimized**: Fast loading with vanilla JavaScript (no heavy frameworks)
- **Interactive Elements**: Smooth scrolling, typing effect, hover animations
- **Sections Include**:
  - Hero landing page with dynamic typing effect
  - About section with personal details
  - Skills showcase with progress bars
  - Featured projects gallery
  - Contact form with social links

## 🚀 Technologies Used

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- Responsive Design
- Modern Web Standards

## 📂 Project Structure

```
My_Portfolio-/
├── index.html       # Main HTML structure
├── style.css        # Complete styling with animations
├── script.js        # Interactive functionality
└── README.md        # Project documentation
```

## 🎨 Design Highlights

- **Color Scheme**: Purple gradient theme (#667eea to #764ba2)
- **Typography**: System fonts for optimal performance
- **Animations**: Smooth fade-in, floating shapes, typing effect
- **Layout**: Modern grid and flexbox layouts
- **UI/UX**: Intuitive navigation with scroll indicators

## 🛠️ How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customize the content with your personal information
4. Update project details, skills, and contact information
5. Deploy to your preferred hosting platform

## 📱 Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers

## 🎯 Customization

To personalize this portfolio:

1. **Update Personal Information**: Edit the HTML content in `index.html`
2. **Modify Colors**: Change CSS variables in `style.css` `:root` section
3. **Add Projects**: Duplicate project cards and update details
4. **Update Skills**: Modify skill cards and progress percentages
5. **Social Links**: Update social media URLs in the contact section
